# NØRTH / CAMP

## Тема проекта
NØRTH / CAMP — концептуальный сайт глэмпинга для изучения территории, выбора домика и оформления бронирования.

## Запуск
1. Скачайте или распакуйте проект.
2. Откройте папку проекта в редакторе кода.
3. Запустите `index.html` через локальный сервер (например, расширение Live Server в VS Code).
4. Откройте предложенный локальный адрес в браузере.

## Основные функции
- Интерактивная карта территории с расположением домиков.
- Фильтрация вариантов по количеству гостей, стоимости и датам проживания.
- Каталог домиков с фотографиями и подробными описаниями.
- Просмотр галереи и отзывов.
- Расчёт стоимости проживания с учётом количества ночей.
- Создание и отмена бронирований.
- Просмотр списка оформленных бронирований.

## Ограничения учебного бронирования
Проект является демонстрационной версией сервиса. Бронирования сохраняются локально в браузере с помощью `localStorage` и доступны только на том устройстве и в том браузере, где были созданы. Серверная база данных, авторизация пользователей, синхронизация между устройствами и реальная оплата не реализованы. Бронирование не является фактическим заказом проживания.

## Использование нейросети
ChatGPT использовался в процессе разработки как вспомогательный инструмент: для генерации и корректировки фрагментов кода, поиска ошибок, доработки логики интерфейса и реализации отдельных функций. Нейросеть не интегрирована непосредственно в пользовательский интерфейс сайта.
